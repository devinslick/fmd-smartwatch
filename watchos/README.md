# watchos/ — FMD Remote for Apple Watch

Standalone watch-only app that talks to an **FMD Server** directly over
the watch's own LTE/Wi-Fi — no bridge APK, no iPhone app, no Android-side
changes. Architecture and decisions: [DESIGN.md](DESIGN.md).

## What exists today

**`fmd-server-core/`** — a cross-platform Swift package (Linux + Apple)
implementing FMD Server **API v2** / Protocol v2 end to end:

- `FmdClient` — salt → login (Argon2id + HKDF) → master-key unwrap →
  `sendCommand(_:)` → `getDataItems(_:)` / `getLocations()`
- Protocol v2 crypto — vendored CC0 Argon2 C reference (`CArgon2` target)
  + swift-crypto (HKDF-SHA256, AES-256-GCM double-envelope with
  context-bound associated data)
- Validated command vocabulary (`ring`, `locate [gps|cell|network|last]`,
  `camera front|back`, `lock`, ringer/DND/Bluetooth toggles)
- **Tests**: 12/12 green on Linux, including golden vectors generated by
  the Python [fmd_api](https://github.com/devinslick/fmd_api) reference —
  byte-for-byte agreement on key derivation, master-key unwrap, KEKs, and
  envelope decryption. The crypto port is proven against an independent
  implementation; only the network layer awaits a live server.

## Build & test (Linux, no Xcode needed)

```sh
cd watchos/fmd-server-core
swift test          # 12 tests incl. cross-implementation vectors
```

Swift 6.1.2+; first build takes minutes (swift-crypto compiles BoringSSL).
The same package compiles unmodified on Apple platforms — the watch app
will `import FmdServerCore`.
